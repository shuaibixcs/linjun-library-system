# 需求验收清单

| 需求编号 | 功能 | 页面或验证位置 |
| --- | --- | --- |
| 1.1 | 管理员账号维护、启停 | 超级管理员 → 管理员账号 |
| 1.2 | 学生新增编辑、批量导入 | 学生管理 → 新增、模板、批量导入 |
| 1.3 | 黑名单及业务拦截 | 黑名单；借阅、预约、入馆接口 |
| 1.4–1.5 | 登录权限、个人资料和密码 | 登录页、角色菜单、个人中心 |
| 2.1–2.2 | 图书与分类维护 | 图书馆藏、图书分类 |
| 2.3 | 批量入库与记录 | 图书入库、入库记录 |
| 2.4 | 书名作者ISBN分类检索 | 图书馆藏筛选、详情 |
| 3.1–3.2 | 借还登记、库存、逾期罚金 | 借阅流通、逾期罚金 |
| 3.3–3.4 | 借阅查询、到期提醒 | 借阅流通筛选、三天内到期、已逾期 |
| 4.1–4.2 | 储物柜维护、审核及到期释放 | 学习空间 → 储物柜；预约管理 |
| 4.3–4.4 | 电子阅览座位、预约签到和违约 | 学习空间 → 座位；我的预约 |
| 4.5–4.6 | 房间维护及预约审核 | 学习空间 → 场馆房间；预约管理 |
| 5.1–5.2 | 活动安排、报名和核销 | 阅读活动、活动报名记录 |
| 5.3–5.4 | 公告维护、置顶、历史和首页 | 馆内公告、服务概览 |
| 6.1 | 今日与历史访客 | 服务概览、入馆登记按日期查询 |
| 6.2 | 学生及校外访客入馆 | 学生顶部入馆登记；管理员入馆登记 |
| 6.3 | 月度借阅、书目排行和分类占比 | 管理员服务概览 |
| 7.1–7.2 | 分页筛选、校验与反馈 | 所有列表、表单与操作消息 |

课程演示中扫码和刷卡通过学号、馆藏编号输入模拟；没有短信、真实支付和独立访客账号。社团申请由学生填写社团名称。罚金只做记录和线下处理状态。上述边界与开发说明一致。
