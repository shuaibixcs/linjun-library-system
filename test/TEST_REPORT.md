# 测试记录

验证日期：2026-10-20。本机 Java 21.0.8、MySQL 9.2.0；代码和建表语法面向 MySQL 8.0+。

## 最终结果

- 22项后端集成测试全部通过，0失败、0错误；同一套用例分别通过H2 MySQL模式和真实MySQL验证。
- Vue生产构建通过。
- Windows初始化、构建、启动、停止脚本语法检查通过；完整构建及本机启动、停止已实际执行。
- 浏览器实际验证管理员与学生登录、实体馆藏查看、借出与归还、学生房间申请、管理员审核及学生状态同步。
- 验收截图保存在 `docs/screenshots/`。

## 自动化业务覆盖

1. 未登录请求和错误密码被拒绝。
2. 学生管理权限与本人借阅数据隔离。
3. 管理员账号管理仅限超级管理员。
4. 图书搜索、分页、首页图表和访客统计。
5. 入库、借出、归还、重复还书与库存一致性。
6. 黑名单学生还书及逾期罚金仅生成一次。
7. 黑名单拦截借阅、预约与入馆。
8. 座位时间冲突与他人预约操作权限。
9. 房间预约与活动冲突、审核冲突、相邻时段。
10. 未签到超时、违约记录与储物柜到期释放，任务重复执行保持一致。
11. 活动重复报名、满额和取消报名后的名额恢复。
12. 可预约时段接口不返回学生身份。
13. 学生创建防角色提权，账号接口不返回密码哈希。
14. Excel重复学号导致整批回滚。
15. 修改密码撤销原登录会话。
16. 按馆藏编号还书和罚金线下处理。
17. 全部业务模块分页查询。
18. 两名学生并发抢同一座位，仅一人成功。
19. 两名学生并发借同一本实体书，仅一人成功。
20. 两名学生并发争抢最后一个活动名额，仅一人成功。
21. 设备损坏阻止预约与签到。
22. 正在进行的活动显示为房间占用。
